## 現在つまずいている問題

### register.html でボタンが表示されない

#### 症状
- register.html を開くとフォームは表示される
- メール入力、ニックネーム入力、チェックボックスは表示される
- しかし「次へ（支払いへ進む）」ボタンが見えない
- ページがスクロールできない
- ボタンがあるはずの位置より下が表示されない

#### 試した対策
1. **CSS変数→直接色指定**: `.register-submit` の color/background を直接指定 → 効果なし
2. **margin-top 追加**: ボタンに余白追加 → 効果なし
3. **disabled時の背景色変更**: グレー背景で目立たせる → 効果なし
4. **インラインスタイル追加**: style属性で強制表示 → 検証中

#### HTML構造（確認済み）
```html
<div class="form-checkbox-group">
  <input type="checkbox" id="agree-terms" ...>
  <label for="agree-terms">...</label>
</div>

<!-- ボタンはここにある -->
<button type="submit" id="submit-button" style="display:block; width:100%; ...">
  次へ（支払いへ進む）
</button>

<div class="register-price">...</div>
```

#### 考えられる原因
1. **CSS の overflow 設定**: 親要素で内容が切り取られている可能性
2. **styles.css との競合**: 外部CSSが上書きしている可能性
3. **ブラウザキャッシュ**: 古いバージョンが表示されている
4. **viewport/height 制限**: 画面高さの制限がある可能性

#### 次のステップ
- シークレットウィンドウでキャッシュ回避してテスト
- styles.css の競合を調査
- ブラウザの開発者ツール（F12）でDOM構造を確認
