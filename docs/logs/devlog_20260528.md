## 3. ✅ チャット対話開始時の相談開始カード自動非表示（2026-05-29 完成）

### 課題（指示書「STEP20 UI改善指示」）
チャット画面で「困っていることを、一言で書いてみてね。」+ カテゴリチップ + 「新しい相談を始める」ボタン（= 相談開始カード）が対話開始後も常時表示され、メッセージ表示領域が狭くて見づらい

### 最終仕様
- **判定方式**: モジュール変数 `chatInteractionStarted: boolean`（セッションスコープ、アプリ起動毎に false にリセット）
- **true にセット**:
  - カテゴリチップ押下時（`setupChatHelperChips` のクリックハンドラ）
  - 送信ボタン押下時（`handleUserMessage` の空文字チェック直後）
- **false にリセット**:
  - 「困りごとを相談する」ボタン押下時（ホーム → チャット入場）→ 戻る/ホーム経由復帰の挙動を満たす
  - 「新しい相談を始める」ボタン押下時（`clearChatHistory` 内）
- **DOM 制御**: `#screen-chat` に `screen--chat-active` クラスを付与/削除 → CSS `.screen--chat-active .chat-helper { display: none !important; }` でカード全体を非表示
- **会話中の「新しい相談」ボタンは表示しない**（指示書通り、ヘッダーミニボタンは削除）

### 旧実装の問題（2026-05-28 中断時のロジック）
- `messages.length > 2` で判定していたため、**オート挨拶**（10-11時 / 16-18時に自動追加される AI 挨拶）や **localStorage 残骸**で起動直後から「対話中」扱いになりカードが消えていた
- ユーザーの「最初は会話切っ掛けなのでカード出しましょう」要望に反していた

### 変更ファイル（2026-05-29 完成版）
- `index.html`:
  - `#btn-new-chat-mini`（ヘッダー右ミニボタン）を**削除**（指示書「会話中は表示不要」）
- `css/styles.css`:
  - `.screen--chat-active .chat-helper { display: none !important; }` のみ維持
  - `.header-action-button` 関連スタイル全削除
- `js/main.js`:
  - `let chatInteractionStarted = false;` 追加（messages 変数の直後）
  - `updateChatHelperVisibility()` をフラグ参照のみに簡素化（messages 配列依存を完全排除、`[helper-visibility]` ログ削除）
  - `handleUserMessage()` 冒頭でフラグ true（空文字チェック後）
  - `setupChatHelperChips()` のチップクリックハンドラでフラグ true + 即時クラス付与
  - 「困りごとを相談する」ボタン（`btnStartChat`）クリックでフラグ false にリセット
  - `clearChatHistory()` 内でフラグ false にリセット
  - `handleNewChat` から `btnNewChatMini` 紐付け削除

### 動作確認（2026-05-29、ローカルブラウザで実証）
- ✅ アプリ起動直後にチャット入場 → カード表示
- ✅ チップ押下 → カード即非表示 + 入力欄にテンプレ
- ✅ 送信ボタン押下 → カード非表示
- ✅ 戻る → ホーム → 「困りごとを相談する」で再入場 → カード再表示（履歴は保持）
- ✅ 会話中にヘッダー右「新しい相談」ボタンが表示されない
