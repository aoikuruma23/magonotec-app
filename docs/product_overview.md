## 1. 30秒ピッチ

**まごのTEC は、スマホ操作に不安のあるご年配の方が、孫に聞くように気軽に質問できるチャット型相談サービスです。**

- 高齢者側：難しい設定なし、URL を開くだけで利用開始
- 家族側：毎週、見守りレポートが届く（利用日のカレンダーと最終利用日時）
- 月額480円（サービス開始テスト期間中の特別価格、通常時 月額980円予定）
- 「教える側の負担を減らす」「会話できる相手をひとり増やす」発想

## 2. 解決する課題

### 高齢者本人の課題
- スマホやネットの「ちょっと困った」を聞ける相手がいない
- 家族に何度も同じことを聞くのが申し訳ない
- お店やサポートに行く前に、何が分からないのかを整理したい
- 迷惑メールや料金プランへの不安を抱えている

### 家族側の課題
- 親に何度も同じことを説明しなくてはいけない負担
- 離れて暮らす親が元気にしているか、毎日電話するのは難しい
- 「最後に話したのいつだったかな」が気になるが、毎回確認はできない
- 介護施設・見守りサービスまでは仰々しすぎる

→ **「日常の小さな困りごと相談」と「ゆるい安否確認」を同時に解決する**のがまごのTEC のポジショニング。

| バリュー | 一言で | 詳細 |
|---|---|---|
| **やさしい応答** | 孫が説明するみたいに | 専門用語を避け、ゆっくり、短い文で答える AI |

## 5. 機能（高齢者側）

### チャット画面
- カテゴリチップから入力できる：**スマホ本体 / 電話・LINE / 写真・カメラ / お金・料金 / その他**
- 「困っていることを、一言で書いてみてね」というやさしい入力ガイド
- 音声入力ボタン搭載（タイピングが難しい人向け）
- 画像添付ボタン搭載（画面のスクショを送って質問可能）
- 「新しい相談を始める」ボタンで履歴クリア

### AI 応答の特徴
- 「まご」キャラ口調（やわらかい敬語、絵文字少なめ）
- 1メッセージを短く・段落分けて表示（読みやすさ重視）
- 設問返し（「カメラのアプリを開いて何が見えますか？」）でユーザーの状況を整理させる
- 失敗を責めない / 急かさない言い回し

### マスコットキャラ
- 画面右下に「まごちゃん」イラスト
- 状態変化：通常 / 考え中 / 安心（AI 応答完了時）
- 親しみやすさと「話している相手がいる」感の演出

### 履歴
- 会話履歴は端末（localStorage）に保存
- 「新しい相談」ボタンで履歴クリア
- サーバーには送信されない

### 時間帯挨拶（オート挨拶）
- 朝（10〜11時）・夕方（16〜18時）に AI からの軽い挨拶
- 季節感を反映（春/夏/秋/冬で文言変化）
- 「今日はどうしてる？」のような押し付けがましくない声がけ

## 6. 機能（家族側）

### 週次見守りレポートメール
**現行の中核機能。** Resend 経由で `noreply@magonotec.com` から送信。

#### 送信タイミング
- **加入日起点の 7 日サイクル**（2026-05-30 から導入）
- 例：土曜日に加入した場合 → 毎週土曜の 9:00 JST にメール
- 自動分散により、1万人規模でも問題なくスケール

#### メール内容
- **利用カレンダー**：直近 7 日間を 〇／ー で表示
- **利用日数**：◯日 / 7日
- **最後にお話しした日時**：YYYY/MM/DD（曜）HH:MM 形式
  - → **「最後に元気だったタイミング」が分かる ＝ ゆるい安否確認**
- **ご利用がなかった日**：日付リスト
- **末尾メッセージ**：「気になることがあれば、お電話やメッセージのきっかけにしてください」

#### 設計思想
> 利用回数の多寡を評価する分析ツールではなく、
> 安否確認に役立つ情報を控えめに届ける見守りツール。

評価や警告の文言は使わない。プレッシャーを与えない。

## 7. 使い方フロー

### Step 1：家族がペアリング登録（5分）
1. `https://aoikuruma23.github.io/magonotec-app/register.html` にアクセス
2. **家族のメールアドレス**を入力（このアドレスに見守りレポートが届く）
3. 利用者のニックネーム（省略可）
4. 利用規約・プライバシーポリシーに同意
5. 「次へ（支払いへ進む）」→ Stripe Checkout で月額480円を決済
6. 決済完了 → 登録完了画面で**親用URL**が発行される

### Step 2：親用URL を高齢者に渡す（5分）
- 登録完了画面に表示される URL（例：`https://.../?pair=4facf...`）を高齢者の端末に送る
- 送信方法：LINE / メール / SMS / 直接入力など何でも可
- 高齢者がその URL を一度開くだけで端末紐付け完了
- ホーム画面追加（PWA）の案内も自動表示される

### Step 3：高齢者が使い始める（即時）
- ホーム画面の「困りごとを相談する」をタップ
- 困りごとを一言入力 → 送信
- AI から段階的な質問が返ってくる → 答えていくうちに状況が整理される
- 完了したら「新しい相談を始める」で次の話題に

### Step 4：家族が見守りレポートを受け取る（自動）
- 加入から 7 日後の同じ曜日 9:00 JST に最初のメール到着
- 以降、毎週同じ曜日に届く
- メール内容を確認、必要に応じて電話・メッセージをする

### Step 5：解約手続き（必要に応じて）
- お問い合わせメール（`jibunkaikakulab@gmail.com`）から解約依頼
- 次回更新日の前日までに手続き完了
- 月末まではご利用可能、月途中の按分返金なし

## 8. 技術仕様 / 信頼性

### システム構成
| 役割 | 技術 |
|---|---|
| フロントエンド | HTML / CSS / Vanilla JS（PWA 対応） |
| 配信 | GitHub Pages（独自ドメイン未使用） |
| バックエンド API | FastAPI（Python 3.10+） |
| バックエンド配信 | Render（Web Service + Cron Job） |
| データベース | PostgreSQL（Render） |
| AI モデル | OpenAI GPT-4o-mini |
| 決済 | Stripe（Live mode 運用中） |
| メール送信 | Resend（独自ドメイン `magonotec.com`、SPF/DKIM Verified、Tokyo region） |

### 個人情報の取り扱い
- **会話履歴は端末（localStorage）のみに保存**。サーバ・DB には送信しません
- DB に保存するのは「ペアリングID（UUID）」「家族のメールアドレス」「利用日（日付のみ）」「Stripe顧客ID」のみ
- 利用者本人の名前・住所・電話番号などは一切取得しません

### セキュリティ
- HTTPS 通信（TLS 1.2 以上）
- pairing_id（UUID v4）による端末認証
- Stripe Webhook 冪等化
- 解約時即時 403 応答（無料アクセス阻止）
- 法規ページ常設（terms.html / privacy.html / tokutei.html / security.html）

### 動作環境
- Chrome / Safari / Edge / Firefox 最新版
- iOS / Android スマホ推奨（PCも可）
- JavaScript / localStorage 有効

## 10. 競合との差別化

| 比較対象 | まごのTEC の優位性 |
|---|---|
| ChatGPT / Gemini 等の汎用 AI | 高齢者向けに UI を極端にシンプル化、敬語・速度・絵文字を調整、家族向け見守りメール付き |
| 介護見守りサービス（カメラ・センサー） | 価格1/10以下、本人が拒否感を持ちにくい（自分用ツール、監視されている感がない）|
| LINE で家族とやり取り | 家族の手間を増やさず、24時間いつでも相談相手がいる |
| スマホ教室 / キャリアサポート | 都度予約不要、家にいる時の細かい困りごとに即対応、家族同伴不要 |

### 強調すべきポジション
- **「教えてあげる」ではなく「自分で聞ける」**：本人の主体性を尊重
- **「見守り」より「ゆるい寄り添い」**：監視・評価しない設計
- **「家族の負担を増やさない見守り」**：週1メール、説明責任は AI 側

## 11. Q&A（販促時に想定される質問）

### Q. 認知症の親でも使えますか？
A. AI チャットの操作（文字入力 or 音声入力 + 送信ボタン）ができれば利用可能です。ただし重度の認知症の場合は介護専門サービスを推奨します。

### Q. 親が話した内容、家族に共有されますか？
A. **共有されません**。会話履歴は本人の端末内のみ。家族に届くのは「何日に利用したか」と「最終利用日時」だけです。

### Q. AI の回答精度はどのくらいですか？
A. GPT-4o-mini ベース。スマホ操作・LINE・写真・料金まわりの一般的な相談に対応。専門医療・法務相談は対象外です。

### Q. 通信費はかかりますか？
A. インターネット接続が必要なため、契約中のモバイル/Wi-Fi の通信費がかかります（追加課金はなし）。

### Q. 月の途中で解約したらどうなりますか？
A. 当該月末までは利用可能、按分返金はありません。次月から課金停止されます。

### Q. 家族のメールアドレスを変えたい
A. お問い合わせメールから変更依頼を受け付けます。

### Q. 私（家族）も同じ URL で使えますか？
A. 技術的には可能ですが、利用日数のカウントは混ざります。家族用にもう1契約することを推奨します（将来的にプラン分けを検討）。

### Q. 親が使わなかった日のメール内容は？
A. 「ご利用がなかった日」に該当する日付がリストアップされ、「最後にお話しした日時」が前回利用日のまま表示されます → 異変を察知するきっかけになります。

### Q. 一人暮らしの親が心配です。これで安心できますか？
A. 完全な安全装置ではありません（緊急通報機能はなし）。あくまで**「ゆるい安否確認」と「相談相手」**としてご活用ください。
